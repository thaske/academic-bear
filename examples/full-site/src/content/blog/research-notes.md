Academic Bear intentionally keeps the site structure simple. You can publish
short research notes, longer essays, course updates, or project announcements
using ordinary Markdown files.

```ts
const idea = "small pieces, loosely joined";
```

The example site keeps helper functions in `src/lib/posts.ts`, but you can adapt
that file however you like.
